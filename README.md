# Week 7 – SQL Assignment

## SQL Query Demonstration

This video demonstrates the successful execution of six SQL queries using phpMyAdmin:

1. SELECT all records
2. SELECT with WHERE
3. SELECT specific columns using aliases
4. INSERT a new record
5. UPDATE an existing record
6. DELETE a record

The INSERT, UPDATE, and DELETE operations include demonstrations of the updated table using Browse.
